# Panels System

This document describes the panels system - a backend-centric approach to real-time dashboard updates.

## Overview

Panels allow users to pin agent-generated artifacts as tabs in the header. Each panel can be configured to automatically refresh its data at a specified interval.

## Core Principles

1. **Backend-Centric**: All data fetching happens on the backend. Frontend only renders.
2. **Two Modes**: Pull-based (polling) or push-based (WebSocket streaming)
3. **Agent-Driven**: Panels are created from artifacts generated by the agent

## Architecture

## Panel Model

```python
class Panel(Base):
    id: UUID                    # Primary key
    user_id: UUID              # Foreign key to user
    artifact_id: str           # Reference to artifact
    name: str                  # Display name
    bq_function: str           # Data function (pnl, risk, fx_rates, etc.)
    bq_params: dict            # Parameters for the function
    refresh_interval: int      # Seconds between updates (0 = disabled)
    is_pinned: bool            # Whether panel is active
    created_at: datetime
    updated_at: datetime
```

### Available bq_functions

| Function | Description |
|----------|-------------|
| `pnl` | P&L attribution data |
| `risk` | Risk metrics (VaR, Greeks) |
| `fx_rates` | Foreign exchange rates |
| `curves` | Interest rate curves |
| `positions` | Position data |
| `news` | Market news |

## Refresh Modes

### Mode 1: Manual Refresh (Default)

- `refresh_interval = 0`
- User manually fetches data via REST API
- No automatic updates

```bash
# Manual refresh
curl /api/v1/panels/{id}/refresh -H "Authorization: Bearer $TOKEN"
# Returns: { "data": {...}, "last_updated": "2024-01-15T10:30:00Z" }
```

### Mode 2: WebSocket Streaming

- `refresh_interval > 0` (e.g., 5, 30, 300 seconds)
- Frontend connects to WebSocket for real-time updates
- Lower latency than polling

```bash
# WebSocket URL
ws://host/api/ws/panels/{id}
```

**Frontend usage:**
```typescript
const cleanup = api.connectPanelStream(panelId, (data) => {
  chart.update(data);
});

// Cleanup when done
cleanup();
```

## Creating Panels via Terminal

### Step 1: Generate Artifact

User asks the agent in terminal:
```
User: "Show my P&L by desk"
```

Agent generates code:
```python
data = bq.pnl()
display.chart(data, chart_type='bar', title='P&L by Desk')
```

### Step 2: Pin Artifact

User clicks the 📌 pin button on the artifact window.

The system creates a panel with:
- Default `refresh_interval = 300` (5 minutes)
- `bq_function` determined from artifact type
- `bq_params` from artifact spec

### Step 3: View as Tab

The pinned artifact appears as a tab in the header, replacing the navigation links.

## Terminal Commands

| Command | Description |
|---------|-------------|
| `!ls` | List all artifacts and pinned panels |
| `!refresh <n> <s>` | Set panel n to refresh every s seconds |
| `!show <n>` | Show hidden artifact n |
| `!del <n>` | Delete artifact n |

### Examples

```bash
# List artifacts and panels
!ls

# Update panel refresh interval
!refresh 0 30      # Panel 0 refreshes every 30 seconds
!refresh 0 300      # Panel 0 refreshes every 5 minutes
!refresh 0 0       # Disable auto-refresh for panel 0
```

## How Refresh Works

### Data Flow

1. User clicks tab with `refresh_interval > 0`
2. Frontend calls `api.connectPanelStream(panelId, callback)`
3. Backend accepts WebSocket connection
4. Backend runs loop: `bq_function(**bq_params)` every N seconds
5. Backend sends `panel_update` messages
6. Frontend updates chart/table with new data

### Implementation Details

**Backend (`panel_service.py`):**
```python
async def stream_panel(websocket, panel_id, user_id):
    panel = await get_panel(panel_id, user_id)
    func = BQ_FUNCTIONS[panel.bq_function]
    
    while True:
        data = func(**panel.bq_params)
        await websocket.send_json({
            "type": "panel_update",
            "panel_id": str(panel_id),
            "data": data,
        })
        await asyncio.sleep(panel.refresh_interval)
```

**Frontend (`+layout.svelte`):**
```svelte
$effect(() => {
  const panel = $panels.find(p => p.id === $activeTabId);
  if (panel?.refresh_interval > 0) {
    const cleanup = api.connectPanelStream(panel.id, (data) => {
      panelData[panel.id] = { data, last_updated: now() };
    });
    return cleanup;
  }
});
```

## Troubleshooting

### Panel not refreshing
- Check that `refresh_interval > 0`
- Verify WebSocket connection is established
- Check browser console for errors

### Data not updating
- Verify `bq_function` is valid
- Check `bq_params` match expected parameters
- Review backend logs for errors

### WebSocket connection fails
- Verify user is authenticated
- Check network connectivity
- Verify refresh_interval is set correctly
